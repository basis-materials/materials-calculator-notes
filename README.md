# Material calculator notes

Original usage notes and worked examples for materials planning tools from Basis Materials.

## Start here

[Calculation examples](docs/calculation-examples.md) covers:

- atomic fraction, mass fraction and the conversion between them;
- an independently calculated 50 at% Cu / 50 at% Ni example;
- theoretical elemental masses for a 100 g batch;
- a thin-film mass example with explicit unit conversions.

## Live tools

| Tool | Planning task |
| --- | --- |
| [Alloy Composition Calculator](https://basismaterials.com/pages/alloy-composition-calculator) | Convert at% and wt%, and plan theoretical batch quantities |
| [Thin Film Material Calculator](https://basismaterials.com/pages/thin-film-material-calculator) | Estimate theoretical film mass from area, thickness and density |

## Scope and assumptions

This repository contains documentation and illustrative calculations. The implementations of the live calculators are not distributed in this repository.

Examples describe theoretical quantities. They do not establish a material specification, processing recipe, inventory commitment, actual deposition consumption or alloy phase prediction.

Basis Materials is a California-based materials supplier serving research and industrial customers. For material-specific requirements, [contact Basis Materials](https://basismaterials.com/pages/contact).
